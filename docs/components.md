# Component inventory

What to reuse before building anything new. This is step 1 of **Reuse first** in [CLAUDE.md](../CLAUDE.md), and it applies to specs and plans as much as to code.

**How to check**

1. Find the job below and use the pick.
2. Not listed? Search `src/components/` and the feature's folder under `src/app/` for it: the name you'd give it, its ARIA role (`role="dialog"`, `role="tab"`), or the words on screen ("No open tasks").
3. Close but not quite? Extend it with a prop or variant. Don't fork a copy.
4. Nothing fits? Pull the control from shadcn's aria registry ([Adding a component](#adding-a-component)). A control the registry lacks is composed from React Aria and stock parts; screens and flows start on Mobbin. Put a general-purpose composition in `src/components/` and add a row here in the same commit.

Paths are under `src/`. Last full sweep: 2026-10-23.

## Adding a component

Stock files come from shadcn's aria registry through the pinned CLI and land in `src/components/ui/` ([design foundation](specs/design-foundation.md), section 5.6).

```sh
npx shadcn@4.23.0 add <name> --dry-run   # the files and packages it would write
npx shadcn@4.23.0 add <name> --view      # the code
npx shadcn@4.23.0 add <name>             # writes into src/components/ui/
node scripts/shadcn-snapshot/snapshot.mjs record <name>   # saves the item's JSON and each written file's hash
node scripts/shadcn-snapshot/snapshot.mjs check           # every stock file still matches (npm test runs it too)
npx shadcn@4.23.0 add <name> --diff      # later: drift from the live registry
```

- **`components.json` stays.** Without it, `add` (even `--dry-run`) runs `init`.
- **Never** `init` in any form, `apply`, `add --all`, `migrate` or `eject`. `init` replaces `lib/utils.ts`, overwrites `:root` with neutral colors, adds a `.dark` block HG never matches, rewrites `--font-sans` and overwrites files.
- **After every `add`:** no diff in `lib/utils.ts` or `app/layout.tsx`, none in `app/globals.css`, and no version bump in the dry run.
- **The table goes by URL, always:** `npx shadcn@4.23.0 add https://ui.shadcn.com/r/styles/base-vega/table.json`, with `--diff` or `--overwrite` the same way. `add table` by name pulls aria-vega's grid, which would change roles on the financial statements. Record it with `record --edit "<why>" <url>` once its one edit is in.
- **The registry is live and unversioned,** so a non-empty `add --diff` is an upstream change: take it to Connor as an update, not a failure. Updates run `add --overwrite` in `src/components/ui/` only, then `record --update`, with `table.tsx`'s edit put back on first. Without `--update`, `record` stops at any recorded file that changed, dependencies included, so it never records a hand edit.
- **Dependencies land in the same folder:** `select` brings `input-group`, which brings `button`, `input` and `textarea`; `sidebar` brings `sheet`, `skeleton`, `tooltip` and `use-mobile`. `record` follows them.
- **A stock file never takes HG classes,** `table.tsx`'s recorded edit aside. Don't pass HG's type roles (`text-body`, `text-meta`), its shadows or its motion names through `className` either: stock files merge classes with the cn package's defaults, which don't know them. Any other misfit goes to Connor.
- **No item?** There's none for a number, search or date field, a date picker's root, a tag group, a meter, a file trigger, a drop zone or a navigation menu. Compose one from React Aria and stock parts; Intent UI's matching item is an anatomy reference only.
- **Touch, focus and motion come from `globals.css`.** Its global rules raise stock controls to 44px (by their `data-slot`) and fields to 16px on touch, cut stock motion to a fade under reduced motion, and ring a picked toggle in ink, so no stock file needs an edit for them. HG's 2px focus outline skips anything with a `data-slot`, which draws its own ring.

## Known gaps

Jobs nothing covers yet, and holes in the picks. The first feature that needs one does the Mobbin research, builds it in `src/components/`, and adds a row above.

- **Tap targets.** The primitives are 44px on touch now. Raw `<button>`s and fields outside `ui.tsx` (filter bars at `h-8`, text links in tables) still warn; move them onto the primitives.
- **Sticky headers on wide tables.** A table wider than its column scrolls sideways in its own box, and a header can't stick to the page from inside a scroll container, so there `Th` scrolls away with the page. Sticking it needs a header synced to the box's scroll. Today that's the rent roll at every width, the equipment table on phones, and the deals list once its columns are dragged wider than the page. The first two are short and the third needs a deliberate drag, so all three can wait until the rent roll lists units.
- **Pending actions.** `Spinner` and `Button` `pending` exist; older pending actions still relabel instead.
